# Changelog

## 0.2.0

- Rewritten in Lit + TypeScript with the same layout and minimal grey / white
  drawing as the vacuum, HP printer and Intelbras solar cards.
- Dish reclined to the real elevation, azimuth compass, signal waves and a
  satellite pass; states for restricted, alerts, obstructed, searching,
  heating, thermal, sleeping, stowed and unavailable.
- Optional built-in Starlink integration: stow / unstow and reboot with
  confirmation, heating / sleep / thermal states; works without
  starlink_local too.
- Visual editor, entity suggestion, en + pt-BR, tests; 0.1.x configs still work.
